САЙТ ДАМИРА: РЕДАКТИРУЕМАЯ КОПИЯ

Это самостоятельная копия исходников текущего лендинга.
Сборка и установка пакетов не нужны.

КАКИЕ ФАЙЛЫ РЕДАКТИРОВАТЬ
index.html: блоки страницы, ссылки, метаданные и начальный русский текст.
styles.css: цвета, шрифты, размеры, отступы и адаптивность.
app.js: тексты на русском и английском, переключатели языка и темы.
assets/: фотографии, иконка сайта и файлы анимации.

Важно: тексты с атрибутом data-i18n берутся из словаря copy в app.js.
Чтобы изменить такой текст, отредактируйте обе версии, ru и en,
а также начальный русский текст в index.html.

КАК ПОСМОТРЕТЬ
Откройте папку в VS Code или другом редакторе.
Удобнее всего запускать index.html через расширение Live Server в VS Code.
Для быстрого просмотра можно открыть index.html двойным щелчком,
но некоторые браузеры ограничивают модульные скрипты при таком запуске.

Если установлен Python 3, откройте Терминал в этой папке и выполните:
python3 -m http.server 4173 --bind 127.0.0.1
Затем откройте http://127.0.0.1:4173
Остановка сервера: Ctrl+C.

ФОТО
assets/damir-cashmere.webp: подключённый цветной портрет в чёрном свитере.
Белая обводка и свечение отсутствуют. Чёрно-белый CSS-фильтр отключён.
Предыдущие варианты сохранены в assets/ и extra-assets/.

ПЕРВЫЙ ЭКРАН
Портрет и English увеличены, боковой текст выровнен по общей сетке.
Кнопка записи белая с синим текстом, включая состояние наведения.
Внешняя серая рамка убрана.

ДОПОЛНИТЕЛЬНЫЕ ПРАВКИ
Приветствие остаётся в Georgia Italic. Имя выделено жёлтым маркером.
Единственный бейдж 16+ перенесён из шапки в секцию о формате занятий.

ПОРЯДОК СЕКЦИЙ
Первый экран, цели и амбиции (синий фон), опыт и образование
(светло-серый фон), практика (белый фон), формат (серый фон), контакты (синий фон).
При добавлении секций чередуем фоны, чтобы соседние блоки не сливались.

СЕКЦИЯ «КОМУ ПОДОЙДУТ ЗАНЯТИЯ»
После синего блока целей добавлены две карточки без иконок и цен.
Длительность 50 или 100 минут указана один раз. Есть RU/EN.
Фоны чередуются: цели синий, аудитория серый, опыт белый,
практика серый, формат белый, контакты синий.

ОБНОВЛЕНИЕ СЕКЦИИ АУДИТОРИИ
Крупный синий заголовок и отдельная курсивная строка соответствуют
остальным секциям. Две открытые колонки с тонкими линиями, без карточек.
Повторы убраны, длительность указана обычным текстом. Формулировка
о свободной речи включена в описание секции практики.
